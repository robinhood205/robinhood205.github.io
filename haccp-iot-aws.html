HACCP × IoT / AWS

温湿度データを自動収集・保存し、食品現場における記録管理、異常検知、現場負担の軽減を検証するIoTシステムです。

技術検証一覧へ

01｜HACCP対応における課題

保健所・コンプライアンスの視点

  • 記録の信頼性不足
  • 管理体制の形骸化

経営者・現場の視点

  • 高額な初期投資の壁
  • 現場のオペレーション負担

02｜サービス紹介・システム構成

① 温湿度計測センサー

メーカー：モノワイヤレス株式会社

  • 温湿度を15分間隔で自動計測
  • 既存設備に後付け可能（レトロフィット）

② GATEWAY

メーカー：モノワイヤレス株式会社

  • センサーからデータを収集
  • Wi-Fiを通じてクラウドへ送信

③ クラウド基盤

AWS（Amazon Web Services）を採用

  • 24時間安定稼働・データ自動保存
  • スマホ・PCからリアルタイム確認可能

03｜実装デモ

温湿度計測センサー

既存設備に後付けする形で温湿度を計測します。

GATEWAY

センサーからデータを収集し、Wi-Fi経由でクラウドへ送信します。

04｜システム Demo

履歴データ照会

デバイスを選択し、期間を指定して温度・湿度の履歴データを確認できます。

異常検知メール

設定した温度範囲から外れた場合、メールによるアラート通知を行います。

05｜技術構成

  • Sensor：TWELITE系 温湿度センサー
  • Gateway：TWELITE Gateway
  • Cloud：AWS IoT Core / DynamoDB / Lambda / API Gateway / S3
  • Frontend：Web Browser（PC・スマートフォン）
  • 通信：センサー → Gateway → Wi-Fi → AWS Cloud

06｜今後の検証

実際の食品現場を想定し、温湿度データの継続的な記録、異常検知、記録作業の効率化などを検証していきます。
