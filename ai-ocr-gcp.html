AI × OCR / GCP

中古スマートフォンと生成AIによる画像解析を活用し、アナログ計器などの現場情報を低コストでデジタル化する技術検証です。

実装デモ

01｜課題

DX初期投資の壁

既存設備を活用しながら、目視で行っていた現場確認をデジタル化することを目指します。

02｜中古スマホによる「画像」のデジタル化

メーターの数値やランプの状態など、目視で行っていた確認作業を自動化します。

特徴

  • 画像から数値を自動判別。
  • アナログ針、旧式液晶、警告灯など多様な表示に対応。
  • 現場のリアル情報をどこでもいつでも確認可能。
  • 安価かつ迅速に導入可能。

03｜概要

温湿度計などのアナログ計器をスマートフォンで撮影し、生成AIによる画像解析を活用して測定値を自動認識します。

事前に計器情報を定義することで、既存設備を活用した低コストなデジタル化を実現します。

04｜特徴

高精度モデル

初回のみ高精度モデルによる計器情報の学習および設定を実施します。

軽量モデル

通常運用時は軽量モデルによる高速・低コストな自動解析を実現します。

JSONデータ化

温度・湿度データをJSON形式で構造化し、端末内へ保存します。

専用機器不要。既存設備を活用したDX化を目指します。

05｜実装デモ

06｜使用技術

  • 開発：Claude Code / Gemini
  • Cloud：Google Cloud Platform（GCP）
  • アプリ：Android Web App
  • データ：JSON形式で端末内へ保存
